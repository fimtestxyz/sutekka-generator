# 贴纸脚本 — 《当工程师开始“管理”20个AI Agent：Lauren Tan的激进实验》

- 套装 slug：`lauren-tan-20-agents`
- 角色：泡泡（小海獭，怀里抱着海星，大黄铅笔）、章章（紫色小章鱼，
  放大镜）、企企（小企鹅，蓝色围巾）。见 `styles/cast-groups/group-02-ocean.png`。
- 本套用**海洋组**（总编辑指定 2026-11-25），不用默认三人组。
  角色表见 `styles/cast-groups/group-02-ocean.png`。
- 真人（Lauren Tan 等）只画通用剪影/背影，绝不画可辨认的真人。

## 三个创意方向（打分，取最强）

| 方向 | 一句话 | 视觉比喻 | 分 |
|---|---|---|---|
| **A. 醒来 20 个已合并** | 她睡了一觉，Agent 自己把 20 个 PR 合并进了主干 | 一张床、一部手机、20 个已合并的 PR | 9/10 |
| B. 信任曲线 | 信任不是一下子给的，是一条从盯梢到放手的曲线 | 一条上升的曲线：微观管理 → 自动合并 | 8/10 |
| C. 护栏 | 她不纠正对话，她改造环境，让错误写不出来 | 一道护栏 + CI 红灯，Agent 走最窄的路 | 8/10 |

**采用 A**，借 B 的曲线给第 3 张，借 C 的护栏给第 4、5 张。醒来收
PR 是整件事最有画面的一幕，也是“管理”这个词最直观的证明。

## 8 张贴纸

### 01 — 一个月 2000 个 PR

- **点**：上个月，她一个人向生产环境合并了 2000 个 PR——演讲的
  标题就是这个数字。
- **画面**：泡泡（小海獭，大黄铅笔）站在一摞高高的 PR 文件旁，文件
  堆得比它还高；头顶一个计数牌写着“2000”。
- **日文**：2000件！
- **中文对照**：一个月2000个PR！

### 02 — 醒来 20 个已合并

- **点**：某天醒来，20 个 PR 已经自己合并进了主干，还通过了事后
  检查。
- **画面**：企企（小企鹅，蓝色围巾）刚从床上坐起来，揉着眼睛，
  手里拿着手机，屏幕上画着 20 个绿色的“已合并”勾。
- **日文**：起きたら20件！
- **中文对照**：醒来20个已合并！

### 03 — 信任曲线

- **点**：信任不是一下子给的，是一条曲线：起初像微观管理者一样
  盯着每一次输出，五个月后醒来收 20 个 PR。
- **画面**：章章（紫色小章鱼，放大镜）指着一块白板上的上升曲线，
  曲线左端写着“微观管理”，右端写着“自动合并”。
- **日文**：信頼カーブ！
- **中文对照**：信任曲线！

### 04 — 护栏

- **点**：她不纠正对话，她改造环境：Agent 每犯一次错，教训就写
  进 Lint 规则或 CI 硬性拦截。
- **画面**：泡泡（小海獭，大黄铅笔）站在一道护栏旁，护栏上挂着
  “CI”牌子；一只小 Agent 机器人想抄近路，被护栏挡住，只能走
  最窄的那条路。
- **日文**：ガードレール！
- **中文对照**：护栏！

### 05 — 禁用 useEffect

- **点**：GrokBot 代码库禁用 useEffect，99% 的代码注释被禁，跨层
  import 会被 CI 直接打回——最窄的路径就是最好的路径。
- **画面**：章章（紫色小章鱼，放大镜）举着一块“禁止”牌子，牌子
  上写着“useEffect”；旁边一个写着注释的纸团被画了叉。
- **日文**：useEffect禁止！
- **中文对照**：禁用useEffect！

### 06 — Dr. Eggbot

- **点**：先拉一个 Dr. Eggbot 当 Bot 设计师，来创建和审计其他 Bot。
- **画面**：企企（小企鹅，蓝色围巾）站在一只蛋形医生 Bot 旁边，
  蛋 Bot 戴着听诊器，正对着一张蓝图设计更小的 Bot。
- **日文**：ドクター・エッグボット！
- **中文对照**：Dr. Eggbot！

### 07 — 小团队

- **点**：Bot 团队保持极小，从零技能起步，同一个失败出现两次才
  固化成 Skill；每个 Bot 有独立邮箱和账号，像真正的团队成员。
- **画面**：泡泡、章章、企企三人围坐在一张小桌旁开会，桌上放着
  三个名牌和三封小邮件。
- **日文**：小さなチーム！
- **中文对照**：小团队！

### 08 — 控制点前移

- **点**：控制点从“代码审查”前移到“环境设计”：与其事后逐行挑
  错，不如事前让错误写不出来。
- **画面**：泡泡、章章、企企三人一起向前走；身后一块路牌写着
  “代码审查”，前方一块路牌写着“环境设计”，箭头指向前方。
- **日文**：前へ！
- **中文对照**：控制点前移！
