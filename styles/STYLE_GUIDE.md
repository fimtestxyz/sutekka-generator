# Sutekka 工作室风格指南

> v1.0 · 2026-11-25 · 风格唯一依据：`art-style/reference.jpg`。
>
> 规则：风格从不照搬。参考图定的是**画风**（Q 版动物、粗黑边、平涂
> 粉彩、白模切边、日文反应语），不是角色。本指南的角色全部是工作室
> 原创，与参考图里的任何具体形象都不相同。

## 1. 工作室固定元素（每套都一样）

读者一眼认出是这个工作室的出品，靠这两样：

### 1.1 固定角色（house cast）

| 角色 | 固定长相 | 担任的角色 |
|---|---|---|
| 黎黎 | 白兔子，圆黑眼镜，别着一支超大黄色铅笔 | 热忱的证明者——相信、宣布、举牌子 |
| 糊糊 | 胖乎乎的青色青蛙，手持放大镜 | 核查者——看代码、量尺寸、问“真的吗” |
| 团团 | 小灰猫头鹰，红围巾 | 怀疑的评论员——泼冷水、指漏洞、说反话 |

长相一旦定死，同一套、不同套之间都不许改——只改姿势和表情，不改
样子。需要专栏里没有的利益相关方时，加客串角色并写明长相，但每套
至少出现一个固定角色。

### 1.2 固定配色

- 纸：白 `#ffffff`（贴纸底）
- 墨：近黑 `#1d1a16`
- 粉彩：粉 `#f6c6d8`、青 `#7fc8bc`、蓝 `#8fb8e8`、橙 `#f2a65a`
- 点缀红：`#b3402a`——只用于最关键的一张，不多用

一套可以加自己的颜色，但不能丢掉白底和墨线，不能滥用点缀红。

## 2. 单张贴纸的画法

- 一个角色，一张贴纸，一个点（§SPEC 4.2）。
- 粗圆黑边，平涂色，无渐变。
- 白色模切边完整不断裂；缩小到 3cm 仍可辨认。
- 日文反应语 ≤15 字，手写体风格，是贴纸的一部分。
- 真人只画通用剪影或背影，不画可辨认的个人。

## 3. 角色怎么选

按贴纸的“点”选，不按心情选：

- 宣布、相信、举牌子 → 黎黎
- 核查、验证、量尺寸 → 糊糊
- 质疑、泼冷水、指漏洞 → 团团
- 两个阵营对峙 → 黎黎 + 团团同框
- 三方各说各话 → 三个全上
